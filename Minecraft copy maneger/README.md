# Minecraft Copy Manager（MOD構成デプロイツール）

MinecraftのMOD倉庫（マスターライブラリ）から、必要なMODをフォルダ・jar単位で柔軟に選択し、Minecraftの `mods` フォルダへ安全・高速に反映（同期/追加）するGUIアプリケーションです。

---

## 主な特徴

1. **マスター倉庫の保護（移動ではなくコピー）**
   - 元のMODフォルダからファイルを移動しないため、整理済みのMODフォルダ構造が壊れません。
2. **三態チェックボックス付き階層ツリー（Tri-state）**
   - フォルダ単位で配下のMODを一括選択/解除可能。
   - 親フォルダをチェックした後に特定のjarだけ個別に外すことができます（親は自動的に半選択状態になります）。
3. **安全な同期モード (Sync Mode)**
   - アプリが配置したファイル一覧を `.minecraft/mods/.modmanager.json`（マニフェスト）に記録します。
   - 選択を解除して再度「同期」を実行すると、本ツールが過去に配置したファイルのみを安全に整理・削除します。
   - **ユーザーが手動で配置したMODは絶対に削除されません。**
4. **追加モード (Add Mode)**
   - 既存のMODを一切削除せず、選択したMODだけを追加・上書きコピーします。
5. **同名MODの衝突検出 (Conflict Detection)**
   - 異なるフォルダから同一ファイル名の `.jar` が同時に選択された場合、事前に警告を表示し、誤配置を防ぎます。
6. **プロファイル管理**
   - 「軽量化・QoL構成」「1.20.1 工業構成」「探索RPG構成」など、チェック状態に名前をつけて保存・ワンクリック復元できます。
7. **無効フォルダのスマート除外**
   - `_backup` や `有効化しないmod` などのフォルダは、初期状態で視覚的に区別・除外表示可能。
8. **安全バックアップ機能**
   - 反映実行時に更新・削除されるファイルがある場合、`.minecraft/mods/.modmanager_backup/` に直前状態を自動退避。
9. **リアルタイム検索 & 折りたたみ差分プレビュー**
   - 入力と連動したインクリメンタル検索。
   - デプロイ前に「➕ 新規」「🔄 更新」「➖ 削除」「⏸️ 維持」のファイル数をリアルタイム表示。
   - **「▼ 差分ファイル詳細を表示」** をクリックすることで、具体的にどのファイルが新規追加・上書き更新・削除されるかを折りたたみツリーで一覧確認可能。各ファイルのサイズや配置元パス、上書き理由も一目で分かります。

## 画面構成と使い方

1. **管理元 (MOD倉庫)**:
   - MODが整理されているフォルダ（例: `D:\Minecraft_mod_management`）を指定します。「参照...」ボタンから選択するか、直接パスを入力してEnterキーを押すとツリーが読み込まれます。
2. **適用先 (mods)**:
   - Minecraftの `mods` フォルダを指定します。Windows標準の `%APPDATA%\.minecraft\mods` が自動で入力されています。
3. **ツリーでのMOD選択**:
   - フォルダ横のチェックボックスをクリックすると配下のMODが一括選択されます。
   - 特定のMODだけチェックを外すことも可能です。
   - 上部の「全選択」「全解除」「選択反転」「すべて展開」「すべて折りたたむ」ボタンも利用できます。
4. **プロファイル管理**:
   - 右上の「＋ 新規保存」で現在の選択状態を名前をつけて保存できます。
   - ドロップダウンから選ぶだけで、一瞬でMOD構成を切り替えられます。
5. **反映（デプロイ）**:
   - 「同期モード（推奨）」または「追加モード」を選択し、緑色の「🚀 modsフォルダへ反映」ボタンを押します。
   - 事前に差分プレビューと確認ダイアログが表示され、安全に配置されます。
